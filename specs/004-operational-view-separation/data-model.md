# Data Model: Separación de Garita Operativa y Dashboard

Esta feature no añade entidades ni campos de datos. Reutiliza las sesiones, las áreas, las unidades de negocio y las métricas ya existentes.

## Secciones visibles por vista

| Vista | Contenido |
|---|---|
| Garita Operativa | Registro de entrada y registro de salida |
| Dashboard | Indicadores generales, distribución por áreas y asignación por unidades |
| Configuración | Contenido actual, sin cambios |

El estado de conexión y sincronización se mantiene transversal a las vistas.
